# DULI Service — сайт клінінгової служби (Одеса)

Статичний багатосторінковий сайт на GitHub Pages: https://sofiy7544.github.io/Sofiya-Duli/

## Як улаштовано

- `build/data.py` — **єдине джерело правди**: контакти, ціни, послуги, FAQ, райони, пакети, гарантії. Усе, що видно на сайті, береться звідси.
- `build/render.py` — шаблони сторінок. Генерує HTML у корінь репозиторію: `index.html`, `services/*/`, `pricing/`, `calc/`, `how-it-works/`, `business/`, `about/`, `faq/`, `privacy/`, `404.html`, `sitemap.xml`.
- `assets/css/site.css` — стилі (mobile-first), `assets/js/site.js` — меню, панель, форми, `assets/js/calc.js` — калькулятор.
- `assets/photos/` — реальні фото робіт, `assets/illus/` — ілюстрації послуг, `assets/icons/` — іконки застосунку, `manifest.webmanifest`.
- `TREES` у `data.py` — лендінг «Обрізка та спил дерев» (`/services/obrizka-ta-spyl-derev/`): заявка за фото йде в Telegram. Місце під фото «до/після» готове — додайте `assets/photos/trees-*.jpg` і згадайте в `TREES`.
- `print/car-magnet/` — макети автомагнітів (двері 600×400, капот-будиночок), на сайт не потрапляють.

## Як змінити щось на сайті

1. Відредагуйте `build/data.py` (наприклад, ціну, телефон, текст FAQ).
2. Запустіть `python3 build/render.py` — HTML перегенерується.
3. Закомітьте й запушіть у `main`. GitHub Actions (`.github/workflows/deploy-pages.yml`) викладе сайт за 1–2 хвилини.

Правити згенеровані `index.html` вручну не варто: наступний запуск генератора їх перезапише.

## Що заповнити, коли зʼявляться дані (`build/data.py`, блок `SITE`)

| Поле | Що дає |
|---|---|
| `instagram` | посилання в підвалі, фіналі, Schema.org |
| `legal` | ФОП/ТОВ у підвалі — довіра для B2B і обережних клієнтів |
| `form_endpoint` | URL, куди форми надсилають заявки самі (пошта/CRM). Поки порожньо — заявка відкриває Telegram із готовим текстом |
| `ga4` | ідентифікатор Google Analytics 4; події вже розставлені (`calc_*`, `booking_submit`, `callback_submit`, `call_click` тощо) |
| `rating`, `rating_count`, `orders_done` | показуються лише якщо заповнені; не вигадувати |
| `OFFERS` | знижка на перше прибирання (%), промокод, сертифікат, «приведи друга» — кожен пункт вмикається окремо |
| `REVIEWS` | список реальних відгуків (імʼя, текст, джерело); секція зʼявляється сама |

Усе, що позначено `# ПІДТВЕРДИТИ` у `data.py`, — твердження, які треба перевірити або прибрати.

## Як заявки доходять до вас

Калькулятор, форма КП і «Передзвоніть мені» формують текст і відкривають Telegram `@Duliser` (або SMS, якщо Telegram нема). Людина натискає «Надіслати». Щоб заявки приходили автоматично, без цього кроку, потрібен `form_endpoint`.

## Перевірка перед викладкою

Локально: `python3 -m http.server 8777` з батьківської папки, відкрити `http://127.0.0.1:8777/Sofiya-Duli/`.
Швидкий чек-лист на телефоні: меню відкривається, калькулятор проходить 5 кроків і відкриває Telegram, прайс розгортається по розділах, нічого не їде по горизонталі.
