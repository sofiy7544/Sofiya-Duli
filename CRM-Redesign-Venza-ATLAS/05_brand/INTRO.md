# Экран входа «фильм» — On Top Property (GSAP)

Анимация на **GSAP 3.15** (npm `gsap`, бесплатная лицензия). Код: `01_preview/source/src/components/brand/intro.tsx` (`FilmLogin`), стили `.film*` в `styles/app.css`.

## Таймлайн (≈6,4 с)
| Время | Кадр |
|---|---|
| 0–1,25 с | iPhone поднимается в кадр (перспектива, blur → резкость), появляется камень и контактная тень, по стеклу проходит блик |
| 0,55–2,1 с | Today оживает: карточка Pipeline value, счётчик €12.4M, растущие столбики, «Offer expected today», строки плана дня |
| 1,95–2,1 с | Первая задача отмечается и зачёркивается |
| 2,35–3,7 с | Dynamic Island раскрывается: New lead · Sophie Laurent · €2.8M |
| 3,4–4,8 с | Свайп в Pipeline: карточка клиента поднимается и переезжает Viewing → Offer, счётчики колонок меняются |
| 4,85–6,1 с | Объект Villa Azure: фото агентства с Ken Burns и сменой кадра, цена считается до €2,450,000, бейдж For sale, Send PDF / Book viewing |
| 5,5–6,4 с | Мягкий наезд → расфокус → логотип и форма входа |

Поверх таймлайна: «дыхание» корпуса (медленный наклон) и параллакс за курсором на десктопе.

- Заголовки над телефоном и боковые подписи убраны по ревью: в кадре только сцена и iPhone.
- Данные в телефоне вымышленные, на английском; форма входа — на русском.
- Раз за сессию; касание / Esc — сразу к форме; `prefers-reduced-motion` — сразу форма.
- iPhone: пропорции современных Pro-моделей (≈0,478), титановая рамка с фасками, тонкая чёрная рамка экрана, Dynamic Island, кнопки Action / громкость / питание / Camera Control, видимая толщина корпуса, лёгкий 3D-разворот, отражение стекла.
- Фото объектов — снимки агентства (10 шт., предоставлены заказчиком), оптимизированы до ≤1200px, JPEG q72, всего ≈1,2 МБ: `src/assets/photos/NN-название.jpg`. Порядок файла = индекс `art` в фикстурах; `PropertyMedia` показывает фото, процедурная сцена — только запасной вариант. В CRM заменить на `BlurImage` с медиа из `/api/uploads`.
- `window.__otpTl` — QA-хук для покадровой проверки (можно удалить при переносе).
