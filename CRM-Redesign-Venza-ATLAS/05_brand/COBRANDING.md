# Кобрендинг входа: RealtorsOS → бренд агентства

Код: `01_preview/source/src/lib/tenants.ts`, `LoginPanel` в `src/components/brand/intro.tsx`, стили `.cob*` в `styles/app.css`.

## Состояния
| Состояние | Что видит пользователь |
|---|---|
| По умолчанию | RealtorsOS: графитовая стеклянная карточка, изумрудно-индиго свечение, «Вход в RealtorsOS» |
| Ввод почты | Поле с анимированной градиентной рамкой; свечение следует за курсором |
| Домен распознан (≥ 3 символа после @) | За ~0,5 с (spring): логотип и заголовок морфятся в бренд агентства («Вход в TOP OS»), карточка светлеет, акцент кнопки и фоновое свечение перекрашиваются, ✓ в поле, бейдж «Powered by RealtorsOS» |
| Неизвестный домен | Плавный возврат к RealtorsOS |
| Вход | Карточка растворяется → «Сегодня» |

Демо-домены: `ontop.property`, `top.com.ua`, `toprealestate.com` → On Top Property; `riviera-estates.com` → Riviera Estates (вымышленное агентство для показа).
В превью почта `demo@ontop.property` впечатывается автоматически после фильма.

## Для CRM
- Публичный эндпоинт `GET /api/tenants/resolve?domain=` → `{ name, short, logoUrl, accent, glow }`. Отвечать брендом по домену, **не раскрывая**, существует ли пользователь (защита от перебора почт).
- Кэш ответов, debounce 250 мс, без запросов до 3 символов домена.
- Бренд агентства хранить в `/settings/branding` (уже есть: логотип, название).
- Не показывать неподтверждённые бейджи безопасности (SOC2, «256-bit» и т.п.) — только фактические.
