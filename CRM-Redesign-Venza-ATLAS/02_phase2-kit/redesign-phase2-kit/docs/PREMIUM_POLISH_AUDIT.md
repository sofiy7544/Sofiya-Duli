# PREMIUM POLISH AUDIT — черновик по документации и записи текущей CRM
Дополняется скриншотами реальных маршрутов на шаге QA (Claude Code, Playwright 320/390/430/768/1440).

## Что выглядит дёшево / шаблонно (найдено)
- **Stock shadcn:** Button/Input/Card без характера; одинаковые `rounded-xl` + `shadow-soft` везде; нет иерархии поверхностей.
- **Перегруз Topbar на мобиле:** 5 иконок подряд (молния, колокол, тема, язык, аватар) — на записи занимают всю строку. → Тема и язык уезжают в «Ещё/Настройки», в топбаре остаются поиск, колокол, аватар.
- **Два H1** на каждой странице (Topbar + страница).
- **~11 разных segmented control** — разные радиусы, высоты, активные стили. → один SegmentedControl с непрерывным индикатором.
- **Glass везде:** kanban-заголовки, табы чата, bulk-бар. → glass только навигация/плавающие контролы/листы.
- **Светлые пятна в тёмной теме:** `bg-white`, `*-50` бейджи, календарные тоны, непрочитанные уведомления.
- **Мобильные карточки лидов без фона** (`bg-card` не существует) — на записи видно «плывущие» строки.
- **Календарь Month на 390px:** точки событий нечитаемы; нет week strip + agenda.
- **Настройки** — стопка одинаковых карточек без группировки.
- **Отчёты:** таблица агентов с нулями — шум; нет пустого состояния.
- **Логин:** фиолетовый градиент не связан ни с одной темой.
- **Технический текст в UI:** `JSON.stringify(rule.action)`, `PATCH /api/users/...` на Team.
- **Смешение языков:** «Захопити лід», хардкод uk/ru.

## Что уже хорошо и сохраняется
44px touch targets, 16px шрифт инпутов на мобиле, safe-area в нижней навигации, tabular-nums, optimistic stage move с Undo, reduced-motion глобально.

## Принципы исправления
1. Три слоя: контент (solid) → навигация/контролы (material) → оверлей (scrim + sheet).
2. Одна сетка отступов на тему; повторяющиеся структуры — одинаковые отступы.
3. Одна иконка на действие (edit=Pencil, more=MoreHorizontal, delete=Trash2, call=Phone, calendar=CalendarDays, client=User, property=Building2, task=CheckSquare, note=StickyNote, filter=SlidersHorizontal, search=Search), stroke 1.75.
4. Анимация только с назначением (ориентация/обратная связь/непрерывность).
