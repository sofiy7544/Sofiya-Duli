# Ручная проверка на iPhone

Автоматика этого не видит. В среде сборки есть только Chromium: движка WebKit нет,
безопасные зоны (вырез, полоса Home), панель Safari и режим установленного
приложения не воспроизводятся. Белая полоса внизу экрана входа прожила до
первого просмотра на реальном телефоне именно поэтому.

Проверять **дважды**: сначала в Safari, затем в приложении с экрана «Домой» —
это два разных режима с разным поведением.

## Перед проверкой
- Открыть в приватной вкладке либо очистить данные сайта, иначе покажется версия из кэша.
- Если приложение уже установлено — закрыть его из переключателя задач и открыть заново.
- Проверять при обеих ориентациях и с включённым «Затемнением» (тёмная тема системы).

---

## A. Safari (браузер)

| # | Что проверяем | Норма |
|---|---|---|
| A1 | Экран входа сразу после загрузки | Фон занимает весь экран, светлых полос сверху и снизу нет |
| A2 | Прокрутить страницу вверх-вниз | Панель Safari прячется и появляется, щель у нижнего края не открывается |
| A3 | Потянуть страницу за нижний край (резиновый отскок) | Из-под контента не выглядывает светлый фон |
| A4 | Нажать на поле «Пароль» | Клавиатура не перекрывает поле и кнопку «Sign in» |
| A5 | Повернуть телефон в горизонт и обратно | Вёрстка не ломается, окно входа остаётся по центру |
| A6 | Войти → экран «Сегодня» | Нижняя навигация не уходит под панель Safari, все 5 кнопок нажимаются |
| A7 | Пролистать «Сегодня» до конца | Последний блок не залипает под нижней панелью |

## B. Приложение (добавлено на экран «Домой»)

Установка: «Поделиться» → «На экран Домой».

| # | Что проверяем | Норма |
|---|---|---|
| B1 | Запуск с иконки | Адресной строки нет, приложение на весь экран |
| B2 | Экран входа | Кадр идёт до самых краёв: над полосой Home нет чёрной полосы, под статус-баром тоже. Края лишь притемнены, фотография видна |
| B3 | Первые полсекунды после запуска | Нет белой вспышки перед появлением фона |
| B4 | Войти в приложение | Область статус-бара становится светлой, в тон интерфейсу |
| B5 | Нижняя навигация | Не налезает на полосу Home, нажимается без промахов |
| B6 | Потянуть список за край | Страница не «отскакивает» целиком |
| B7 | Свернуть и вернуться через переключатель | Состояние сохраняется, повторной загрузки нет |
| B8 | Включить авиарежим и открыть приложение | Открывается из кэша, а не белым экраном |

## C. Общее для обоих режимов

| # | Что проверяем | Норма |
|---|---|---|
| C1 | Экраны: Сегодня, Лиды, канбан, карточка лида, Объекты, Задачи, Календарь | Горизонтальной прокрутки нет нигде |
| C2 | Поля даты и времени (карточка лида, календарь) | Нативные окна iOS открываются, поле не распирает вёрстку |
| C3 | Темы: ATLAS, Сепия, Venza | Переключаются, текст читается на всех подложках |
| C4 | Смена языка в настройках | Меняются форматы дат и чисел; подписи в превью русские (перевод — в CRM) |
| C5 | Мелкие кнопки: сердце, стрелка, вкладки, чипы этапов | Попадание с первого раза (цель от 44 px) |
| C6 | Видео на фоне входа при мобильном интернете | Загружается без долгого чёрного экрана; при «Экономии трафика» показывается неподвижный постер |
| C7 | Первые секунды после открытия сайта | Кадр появляется сразу и едет с первой секунды: заставка в index.html не ждёт загрузки приложения, приложение подхватывает движение без рывка |
| C8 | «Уменьшить движение» в настройках iPhone | Фотография на входе остаётся, но неподвижная (не пустой чёрный экран) |
| C9 | Экран входа в режиме энергосбережения (жёлтая батарея) | iOS запрещает автозапуск: сначала виден постер с наездом, после первого касания экрана видео запускается |
| C10 | Новое событие в календаре | Пресеты и точное время; «Перенести» меняет только начало, длительность сохраняется; «Проведено» убирает из календаря и оставляет в истории клиента |
| C11 | Колокольчик на телефоне | Доступен с любого экрана: «Ещё» → первая строка |
| C12 | Выход из аккаунта | Настройки → внизу, с подтверждением, уводит на экран входа |
| C13 | Срок в листе «Новая задача» | Пресеты + «точное время»: поле открывает системный барабан, как в будильнике; прошедших пресетов в списке нет |
| C14 | Отметить задачу, дождаться чёрной плашки и сразу нажать «+» | Плашка стоит выше кнопки и не перехватывает нажатие |
| C15 | Прокрутить список клиентов, открыть карточку, вернуться назад | Список открывается на том же месте, а не сверху |
| C16 | Начать печатать почту на входе, не дожидаясь анимации | Подставляемый адрес пропадает, печатается только ваш текст |
| C17 | Вкладки на экране «Задачи» на узком телефоне | «Готово» видно целиком; ряд прокручивается пальцем |
| C18 | Поиск: «Ницца», «Эз», почта клиента, имя лида | Находит объекты по русскому написанию района и открытые лиды отдельной группой |
| C19 | Колокольчик, когда разбирать нечего | Красной точки нет; в панели — «Уведомлений пока нет» |
| C20 | Прокрутить список вниз, открыть карточку, вернуться и сразу нажать «+» | Кнопка на месте: восстановление позиции её не прячет |
| C21 | Лид → «Назначить показ» → тап по времени | В системном барабане нет кнопки «Сбросить»: поле обязательное |
| C22 | Если «Сбросить» всё же появилась — нажать её | Поле пустеет, под ним «Выберите время показа», кнопка «Назначить» гаснет; выбор времени снова её включает |
| C23 | Лиды → ряд этапов | Правый край растворяется: видно, что ряд листается. Долистали вправо — справа край чёткий, растворяется слева |
| C24 | Там же, полоска под фишками | Бегунок занимает примерно половину дорожки и едет вместе с рядом; долистали — упёрся в правый край |
| C25 | «Сегодня» в тёмном режиме, тема Venza, в разное время суток | Заголовок «Доброе утро / день / вечер» читается: подложка шапки темнеет вместе с темой |
| C26 | Долистать список лидов до низа | Строки подгружаются сами, под списком «Показано 50 из N» и кнопка «Показать ещё» |
| C27 | Долистать, открыть карточку, вернуться назад | Список того же объёма и та же позиция, а не первые пятьдесят строк сверху |
| C28 | Список, где всё влезает (например, объекты) | Кнопки и счётчика нет вовсе |
| C29 | Новое событие → поле «Клиент» | Над списком поле поиска; набрали фамилию — список сузился; очистили поиск — выбранный клиент остался |

## Если нашли расхождение
Записать: режим (Safari или приложение), модель iPhone и версию iOS, экран,
скриншот. Без этих четырёх пунктов воспроизвести баг сложно: поведение
отличается между версиями iOS и между двумя режимами.
