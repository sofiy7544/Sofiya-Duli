# Автомагніт DULI Service — 600 × 400 мм

Макет для друку на магнітному вінілі, дві сторони авто (Dacia Logan MCV).

- `magnet.html` — джерело макета. `?side=left` (ведмідь ліворуч, для лівого борту), `?side=right` (ведмідь праворуч, для правого борту), `&guides=1` показує лінії обрізу та безпечної зони.
- `export.js` — експорт у PDF (610 × 410 мм, векторний текст) і PNG 150 dpi. Запуск із кореня репозиторію: `python3 -m http.server 8777`, потім `node print/car-magnet/export.js`.
- `bear-cut.png` — ведмідь без фону (вирізано з логотипа), `qr.png` — QR на сторінку розрахунку.

Формат: обрізний 600 × 400 мм зі скругленими кутами (радіус 15 мм по лінії різу), вильоти 5 мм з кожного боку (аркуш 610 × 410, радіус 20 мм), безпечна зона — 20 мм від краю аркуша. PNG має прозорі кути. Фон #1D402C, текст білий, слоган #BFE6CE.

## Варіант «щит» (фігурний магніт)

- `shield.html` — макет у формі геральдичного щита зі стрічкою зверху; форма симетрична, один файл на обидва борти. `?guides=1` показує контур різу, `?contour=1` — лише контур.
- `export-shield.js` — експорт: `DULI-magnet-shield-410x510mm.pdf` (друк), `…-150dpi.png` (прозорий фон), `DULI-magnet-shield-cut-contour.pdf` (контур різу окремим файлом, маджента 0,3 мм).
- Аркуш 410 × 510 мм, сам щит по контуру різу 390 × 456 мм. Біла окантовка 7 мм усередину від різу, назовні біле поле як вильот. Різ по одному замкненому контуру.
